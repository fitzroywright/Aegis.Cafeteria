# Aegis.Cafeteria v54

## Recent transaction visibility

- Recent Transactions — Today is now an idle/between-customers view only.
- As soon as an employee or Cash Customer is selected, the recent-transactions panel collapses and its layout space is returned to the active sale.
- The panel returns after **New Customer** or the configured inactivity reset clears the active customer.
- Windows and Linux use the same behavior.
- No checkout, funding, FFP publication, reporting, persistence, or database schema behavior changed.
- SQLite schema remains version 48.
