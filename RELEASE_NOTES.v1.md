# Aegis.Cafeteria v1

- Resets the release numbering from the former v100 lineage to the new v1 baseline.
- Future packages use `Aegis.Cafeteria.vN.zip`; the `Rewrite` package name is retired.
- Applies the supplied FFP icon to the Windows executable so Start menu/taskbar shortcuts inherit the FFP icon.
- Applies the same FFP icon to the Windows main form and operator login form.
- Makes the operator login form always-on-top.
- Normalizes the supplied 32x13 icon into a multi-resolution Windows ICO while preserving aspect ratio with transparent padding.
- Retains the Development-only Swagger and combined Services + Windows POS Visual Studio startup profile from the former v100 baseline.
