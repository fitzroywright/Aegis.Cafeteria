# Aegis.Cafeteria v55

## UI layout correction

- Restores the original Windows transaction workspace proportions and structure during an active customer/sale.
- Recent Transactions - Today is no longer a row inside the transaction workspace.
- Recent Transactions is now a separate idle-only view shown only when no customer/transaction is active.
- Selecting an employee or Cash Customer restores the original transaction workspace wholesale.
- New Customer, completed-sale reset, and inactivity reset return to the idle Recent Transactions view.
- Linux continues to hide its recent-transactions row completely during an active transaction, preserving the transaction workspace.
- No checkout, funding, FFP publication, reporting, persistence, or schema changes.
