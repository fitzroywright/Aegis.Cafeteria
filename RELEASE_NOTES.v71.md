# Aegis.Cafeteria v71

## Login keyboard navigation
- Windows operator sign-in now has an explicit keyboard tab order:
  1. Username
  2. Password
  3. Sign In
- The status label is non-tabbable.
- Enter still activates Sign In through the form AcceptButton.

## FFP integration
- No FFP database schema or publishing behavior changed from v70.
- `FfpIntegration:Enabled=true` continues to enable FFP reference refresh and the durable FFP ledger publisher.
